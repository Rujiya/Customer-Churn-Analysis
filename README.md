# 📊 Customer Churn Analysis

## 📌 Project Overview

Customer churn is an important business problem for telecom companies. 
This project analyzes customer data to understand why customers leave and 
identifies customers who may be likely to churn.

The project combines SQL, Power BI, Python and Machine Learning to create 
an end-to-end data analytics solution.

---

## 🎯 Objectives

- Analyze customer churn patterns
- Identify major reasons for customer churn
- Analyze churn based on customer demographics
- Analyze churn based on services and payment methods
- Calculate important business KPIs
- Predict customers who are likely to churn

---

---

## 📂 Project Workflow

### 1. Data Preparation
Customer data was prepared and transformed using SQL Server.

### 2. Data Analysis
SQL was used to explore customer information and identify important 
churn-related patterns.

### 3. Power BI Dashboard
An interactive dashboard was created to visualize:

- Total Customers
- Total Churn
- Churn Rate
- New Customers
- Churn by Gender
- Churn by Contract
- Churn by Payment Method
- Churn by Internet Type
- Churn by Age Group
- Churn by Churn Category
- Churn by Services

### 4. Machine Learning

A Random Forest Classifier was implemented using Python and Scikit-learn 
to predict customer churn.

The model was trained using historical customer information and used to 
identify customers who may be at risk of churning.

---

## 📊 Dashboard

The Power BI dashboard provides an interactive view of customer churn 
and allows users to explore different customer segments.

---

## 🤖 Machine Learning

### Model Used

Random Forest Classifier

### Purpose

The model predicts whether a customer is likely to churn.

The predicted results were then used to identify potential churners.

---

## 💡 Key Insights

The analysis helps businesses understand:

- Which customer groups have higher churn
- Which contracts have higher churn
- Which payment methods are associated with churn
- Which services influence customer retention
- Why customers leave the company
- Which customers may be at risk of leaving
